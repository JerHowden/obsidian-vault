## Competency 007

> The computer science teacher correctly and efficiently uses data types, data structures and functions in the development of code.

1. Understands various computer-related number-base systems and uses them to count, convert and perform mathematical operations.
2. Understands the characteristics of standard data types in current programming languages (e.g., integer, floating point, character, string, Boolean).
3. Demonstrates the ability to develop code using constants, variables, data structures and appropriate scope (e.g., local, global).
4. Understands the difference between primitive and referenced data types (e.g., objects, lists).
5. Demonstrates the ability to cast between data types and provide object functionality to primitive data types.
6. Demonstrates effective use of standard libraries (e.g., math, string) in the development of code.
7. Demonstrates the ability to create user-defined functions and procedures.
8. Demonstrates understanding of the difference between parameters that are passed by value or by reference.
9. Knows how to identify object-oriented data types and how to delineate the advantages and disadvantages of object data.
10. Demonstrates the ability to process data in one-dimensional and multi-dimensional arrays.
11. Understands how to implement input/output processes (e.g., file, keyboard).
12. Demonstrates the ability to manipulate text using string processing functions (e.g., concatenation, substring, search).
13. Understands concepts related to the traversal and processing of abstract data types (e.g., stacks, queues, linked lists, trees, graphs).

## Competency 008

> The computer science teacher correctly and efficiently uses statements and control structures in the development of code.

1. Creates mathematical expressions using arithmetic operators (addition, subtraction, multiplication, division, integer division and modulus division).
2. Develops programs using standard operators (e.g., arithmetic, relational, logical, assignment), operator precedence and short-circuit evaluation.
3. Demonstrates an understanding of conditional and iterative control structures.
4. Demonstrates coding proficiency in current programming languages, including an object-oriented language.
5. Demonstrates understanding of object-oriented design and the relationships (including composition and inheritance) among defined classes, abstract classes and interfaces.
6. Designs classes that encapsulate data and related methods.
7. Demonstrates understanding of polymorphism in overloading and overriding features of classes.
8. Demonstrates the ability to use abstract classes and interfaces to design and implement multi-class programs.

## Competency 009

> The computer science teacher knows how to construct, compare and analyze various algorithms.

1. Constructs searching algorithms (e.g., linear and binary searches).
2. Constructs sorting algorithms including, but not limited to, selection, insertion, merge and quick sorts.
3. Analyzes the best-, averageand worst-case run-time efficiencies of various algorithms using informal comparisons and Big-O notation.
4. Traces, compares and uses iterative and recursive algorithms.
5. Demonstrates an understanding of and the ability to develop common algorithms to solve practical problems.
